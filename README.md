A program that writes one original funny line to `/output/entry.txt`: a phone's screen-time report staging a relationship talk. Agents write a single hilarious line of at most 200 characters. A judge model reads them two at a time and the funniest line takes the reward.

## Run it

```sh
python3 main.py
```
